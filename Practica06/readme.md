## 📌 01. Descripción del proyecto

Esta práctica consiste en la elaboración de un **diagrama interactivo de secuencia de pantallas de Netflix**, desarrollado mediante bocetos de interfaz de baja fidelidad (*sketches*).

El proyecto tiene como finalidad representar de forma visual la navegación de una aplicación móvil de entretenimiento, mostrando cómo se relacionan sus diferentes pantallas y qué acciones puede realizar el usuario durante su recorrido.

A través de las maquetas se representan funciones como el inicio de sesión, la selección de perfiles, la búsqueda de películas y series, la reproducción de episodios y la administración de la cuenta.

También se incluyen pantallas relacionadas con las descargas, las listas personales, la configuración, el control parental y la ayuda al usuario.

El diagrama permite comprender la estructura general de la aplicación, identificar las principales funciones y observar cómo se organiza la experiencia de navegación.

## 🎯 02. Objetivo

Diseñar y documentar un diagrama interactivo que represente la secuencia de pantallas de una aplicación móvil inspirada en Netflix, identificando sus principales interfaces, categorías, acciones y respuestas del sistema.

### ✨ Objetivos específicos

- 📱 Representar las principales interfaces de una aplicación de streaming.
- 🧭 Organizar las pantallas mediante un flujo lógico de navegación.
- 🎨 Elaborar bocetos para visualizar la estructura de cada interfaz.
- 👤 Identificar los roles y las categorías contempladas en el modelo.
- 🔎 Facilitar la búsqueda y exploración de las pantallas.
- ⚙️ Representar respuestas del sistema y estados alternativos.
- 📚 Documentar el proyecto para su presentación académica.

## 🔄 04. Recorrido de navegación

El flujo comienza con la pantalla de bienvenida, desde donde el usuario puede acceder al inicio de sesión. Posteriormente, se representa la verificación de la cuenta y la selección del perfil correspondiente.

Una vez dentro de la aplicación, el usuario puede explorar las novedades, buscar contenido y consultar los detalles de una película o serie. Si se trata de una serie, puede revisar los episodios disponibles y continuar hacia el reproductor.

El recorrido también incluye opciones para guardar contenido en Mi lista, consultar descargas, administrar perfiles y revisar la información de la cuenta.

Finalmente, se presentan funciones de configuración, accesibilidad, control parental, ayuda y soporte, además de un panel administrativo incorporado al modelo académico.

### 🎞️ Flujo general

`Bienvenida` → `Inicio de sesión` → `Verificación` → `Selección de perfil` → `Inicio` → `Búsqueda` → `Detalles` → `Episodios` → `Reproductor`

Desde las pantallas principales también se puede explorar el acceso a las funciones complementarias representadas en el diagrama.

## 👥 06. Roles y categorías

### 🔓 Acceso
Agrupa las interfaces de bienvenida, inicio de sesión, verificación y selección del perfil.

### 🍿 Usuario / suscriptor
Representa al usuario que explora contenido, reproduce películas y series, administra sus listas y consulta las opciones de su cuenta.

### 🛠️ Administrador académico
Representa las funciones administrativas contempladas en el modelo, como la gestión de información y la consulta de cambios.

### ⚙️ Sistema
Representa las respuestas e interacciones que pueden producirse durante la navegación, incluidos mensajes de error, verificaciones, permisos y confirmaciones.

> **Nota:** Las categorías describen el modelo académico de la práctica. No todas representan necesariamente roles o funciones oficiales de Netflix.

## 🧩 07. Funcionalidades interactivas

El diagrama incorpora herramientas que permiten explorar las maquetas de manera sencilla:

- 🔴 **Filtros por categoría:** permiten mostrar las pantallas de cada grupo.
- 🔎 **Búsqueda:** facilita localizar una pantalla por nombre o función.
- 🗂️ **Tarjetas interactivas:** presentan una vista previa de cada interfaz.
- 🔍 **Vista ampliada:** permite observar una maqueta con mayor detalle.
- ❎ **Cierre de vista:** permite regresar al diagrama general.
- 🏷️ **Etiquetas visuales:** ayudan a identificar las categorías.
- 🧭 **Organización del flujo:** facilita comprender la secuencia de navegación.

## ⚙️ 08. Instrucciones de uso

1. Abre el [diagrama interactivo de Netflix](https://jenniferbautistabarrios.github.io/Practicas-Integradora/Practica06/sketches-moviles.html).
2. Espera a que se cargue la página.
3. Explora las tarjetas que representan las diferentes pantallas.
4. Utiliza los filtros para visualizar una categoría.
5. Escribe el nombre de una pantalla en el campo de búsqueda.
6. Selecciona una tarjeta para ampliar su maqueta.
7. Observa los elementos y las funciones representadas.
8. Presiona `Escape` o utiliza el botón `×` para cerrar la vista ampliada.

También puedes abrir el archivo `netflix-secuencia-pantallas.html` directamente en un navegador, siempre que los recursos necesarios estén disponibles.

## 🎨 10. Alcance visual

Las pantallas son **bocetos de interfaz creados con fines académicos**. Su propósito es representar la estructura, la navegación y las funciones principales de una aplicación de streaming.

Los elementos visuales toman como referencia patrones habituales de este tipo de plataformas, como tarjetas de contenido, botones, listas de episodios, perfiles y opciones de configuración.

Las maquetas permiten concentrarse en el flujo de navegación sin necesidad de implementar todos los servicios de una aplicación comercial.

El contenido es ilustrativo y no corresponde necesariamente a capturas oficiales ni a una implementación funcional de Netflix.
